# Logos

Знак DAYCELL — кольцо `ink` + ядро `energy`: солнце внутри ячейки, день, сохранённый как заряд.

- `daycell-mark.svg` — основной знак, обводка 5/100. От 48px.
- `daycell-mark-small.svg` — для 16–40px (фавикон, вкладки): толще кольцо, крупнее ядро.
- `daycell-mark-inverse.svg` — знак на тёмной плашке (иконка соцсетей, тёмные носители).

Словесный знак набирается: «DAYCELL», Barlow Condensed 700, трекинг +0.01em, капс. Горизонтальная версия: знак высотой 0.9 капа слова, зазор 0.3 высоты знака. Альтернатива без знака: «DAYCELL» + янтарная точка `energy` на базовой линии.
Охранное поле — половина диаметра знака. Ядро всегда `energy`; монохромная версия — ядро `ink`. Не вращать, не добавлять лучи, тени, градиенты.
