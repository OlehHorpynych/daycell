# Frame

Рамка-витрина: экран как отдельный объект на светлом `canvas` — белая обводка 6px (`frame`), `radius-frame`, лёгкая тень `shadow-frame`. Поля `space-14` × `space-20`. Контент прижат к четырём углам, центр отдан визуалу (объект, панель, ключевая цифра). Один Frame на экран; внутри — без вложенных скруглённых карточек.
